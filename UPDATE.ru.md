# Обновить с сохранением данных

Поддерживается стандартная установка старого `awg-docker-bot` со службой `awg_bot` и рабочей папкой, заканчивающейся на `/awg`, а также эта версия менеджера. Для нестандартной службы используйте `AWG_SERVICE_NAME`, для каталога — `AWG_INSTALL_DIR`.

## Обновление одной командой

```bash
bash -c 'set -e; run_root() { if [ "$EUID" -eq 0 ]; then "$@"; else sudo "$@"; fi; }; command -v git >/dev/null || { run_root apt-get update; run_root apt-get install -y git ca-certificates; }; task_dir=$(mktemp -d); trap "rm -rf -- \"$task_dir\"" EXIT; GIT_TERMINAL_PROMPT=0 git clone --depth 1 https://github.com/wickedslim/amnezia-vpn-manager.git "$task_dir"; run_root bash "$task_dir/update.sh"'
```

Команда скачивает актуальную ветку `main` в новую временную папку, запускает установщик и удаляет только эту временную копию после завершения. Если Git отсутствует, установит Git и сертификаты через apt. Запускайте в терминале VPS (Ubuntu/Debian); если вы не root, потребуется sudo.

Репозиторий открытый: аккаунт GitHub, приглашение и токен для скачивания не нужны.

Текущий режим (бот / бот с Mini App) сохранится. Скрипт создаст резервную копию перед заменой кода. Для отключения Mini App добавьте `--bot-only` после `"$task_dir/update.sh"` внутри одинарных кавычек. Если скачивание завершится ошибкой, установщик не запустится.

## Получить отдельную копию новой версии вручную

Скачайте свежий ZIP из репозитория и распакуйте в **отдельную** папку. Не распаковывайте поверх рабочего каталога бота.

При использовании Git обновляйте отдельный checkout:

```bash
git -C /path/to/source-checkout pull --ff-only
cd /path/to/source-checkout
```

## Обновить

```bash
sudo bash update.sh
```

Этот вариант сохраняет текущий режим: чат-бот продолжает работать, существующий Mini App и настройки HTTPS остаются подключёнными.

Чтобы отказаться от Mini App и использовать только чат:

```bash
sudo bash update.sh --bot-only
```

Веб-API отключится, кнопка Mini App сменится меню команд. База, статистика и конфиги сохранятся. Настройки Caddy/DNS автоматически не удаляются: прокси может обслуживать другие сайты. При необходимости удалите только свой блок домена вручную.

Начиная с beta.5, для перехода с обычного бота запустите `sudo bash update.sh` в интерактивном SSH-терминале. Выберите **1 — свой домен** или **2 — бесплатный DuckDNS**, направьте адрес на IP VPS с ботом и введите его в мастере. После проверки DNS продолжится настройка HTTPS. [Пошаговая инструкция](MINIAPP.ru.md#переход-с-обычного-бота-на-mini-app-с-beta5).

Для подключения Mini App без мастера:

```bash
sudo bash update.sh --domain vpn.example.com --ip 203.0.113.10
```

Если HTTPS уже настроен, не передавайте `--domain` повторно; используйте обычный `update.sh`.

Пример нестандартного пути:

```bash
sudo AWG_INSTALL_DIR=/root/awg-docker-bot bash update.sh
```

## Что сохраняется и что происходит

1. Новые зависимости устанавливаются в отдельное окружение до остановки бота; предыдущие окружения остаются для отката.
2. Перед заменой сохраняются рабочие файлы и БД в `/var/backups/amnezia-manager/ДАТА-PID`, а также прежний unit службы.
3. Настройки читаются из `awg/files/setting.ini`; серверы/лимиты/доступные конфиги старой версии импортируются однократно. Новая SQLite не заменяется пустой.
4. Код проверяется и перезапускается **только бот**. VPN-контейнеры и интерфейсы не перезапускаются.
5. При ошибке этапа обновления восстанавливаются предыдущие файлы/unit/настройка интерфейса. Настройка HTTPS — отдельный этап: при его отказе сам установленный бот остаётся рабочим.

## После обновления

Откройте `/servers`, проверьте количество серверов и клиентов, карточки, трафик и выдачу сохранённого конфига. Первую проверку создания/удаления делайте на отдельном тестовом клиенте. Логи: `sudo journalctl -u awg_bot -n 100 --no-pager`.

**Направления отображения изменены намеренно:** ↓ на устройства, ↑ с устройств. Сами накопленные байты в БД не переставляются, месячные суммы не пересчитываются.
