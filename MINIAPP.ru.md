# Mini App: по желанию

Чат-бот работает самостоятельно. Для отказа от Mini App при установке/обновлении используйте --bot-only. Режим «Бот + Mini App» требует собственного HTTPS-домена.


## Переход с обычного бота на Mini App (с beta.5)

Скачайте новую версию в отдельную папку, не поверх работающего бота, откройте эту папку в SSH-терминале и выполните:

```bash
sudo bash update.sh
```

В мастере выберите `1` — свой домен, `2` — бесплатный DuckDNS, `3` или Enter — только чат. При выборе DuckDNS:

1. Проверьте показанные IP интерфейсов. При NAT введите внешний публичный IP VPS с ботом.
2. Откройте https://www.duckdns.org/, войдите, создайте свободное имя, укажите IP VPS и сохраните.
3. Введите в установщике полный адрес, например `my-vpn.duckdns.org`, без `https://` и пути. Токен DuckDNS не нужен. При смене IP обновите запись на сайте.
4. Если DNS ещё не обновился, Enter повторяет проверку, `1` меняет адрес, `0` продолжает установку без панели.
5. После проверки A/AAAA установщик продолжит обновление с резервной копией и настройкой HTTPS. Нужны свободные и доступные извне TCP 80/443. Чужие сайты Nginx/Caddy не заменяются.

База, серверы, конфиги и статистика сохраняются. VPN не перезапускается; бот кратко перезапускается при обновлении и настройке HTTPS. После завершения переоткройте чат и нажмите «Панель VPN».

Если панель уже подключена, мастер повторно не появляется. Без интерактивного терминала обновление сохраняет режим. `--bot-only` оставляет только чат, `--domain` позволяет подключить свой адрес без мастера. При ошибке HTTPS бот остаётся установленным; исправьте DNS/прокси и повторите только `scripts/install-miniapp.sh`, как показано ниже.

## Автоматическая настройка после установки бота

Создайте DNS A поддомена на IP VPS с ботом; проверьте также AAAA. Откройте TCP 80/443. На Ubuntu/Debian со свободными веб-портами:

```bash
sudo bash scripts/install-miniapp.sh vpn.example.com 203.0.113.10
```

Установщик обнаруживает каталог и Python действующей службы awg_bot. При нестандартной установке доступны AWG_INSTALL_DIR, AWG_SERVICE_NAME, AWG_PYTHON, AWG_WEB_PORT.

Если уже настроен Caddy/Nginx или веб-порт занят, автоматическая настройка прекращается без замены чужих сайтов. Используйте существующий HTTPS-прокси.

## Ручной HTTPS-прокси

В systemd drop-in службы:

```ini
[Service]
Environment=AWG_WEB_DISABLED=0
Environment=AWG_WEB_HOST=127.0.0.1
Environment=AWG_WEB_PORT=8088
Environment=AWG_WEB_URL=https://vpn.example.com
```

Если ранее включали --bot-only, замените Environment=AWG_WEB_DISABLED=1 в zz-interface.conf на 0. Затем systemctl daemon-reload и перезапуск только бота.

Пример блока Caddy:

```caddy
vpn.example.com {
    encode zstd gzip
    reverse_proxy 127.0.0.1:8088
}
```

Python API должен оставаться на loopback. Caddy получает и обновляет сертификат автоматически при доступных DNS/80/443.

## Вход и данные

Кнопка «Панель VPN» устанавливается владельцу в личном чате бота. Все запросы /api/* проверяют HMAC-SHA256 подписанных Telegram initData, возраст до часа и ID владельца. После истечения сессии переоткройте Mini App. Настройки SSH и приватные конфиги не возвращаются общими запросами; получение доступного конфига — отдельный защищённый запрос. CORS не включён, ответы не кешируются.

Веб-панель использует тот же процесс, базу и блокировки VPN, что и чат-бот. Второй polling-процесс не запускается. Настройка новых серверов и SSH-реквизитов пока остаётся в чат-боте.

## Измерения

VPN: ↓ На устройства, ↑ С устройств. График показывает среднее по двум последним успешным замерам. Активное Mini App делает запросы раз в 5 секунд; сервер объединяет опрос разных вкладок. Фон бота работает раз в 60 секунд.

Системный VPS: все службы на основном сетевом интерфейсе, подписи «VPS получил / VPS отправил». Сохраняется раз в минуту в фоне. Начальные значения берутся из текущих системных счётчиков; более ранняя история неизвестна.

Speedtest измеряет канал самого сервера до выбранного тестового узла и временно занимает полосу. Установка утилиты — только после подтверждения пользователя. Условия Ookla автоматически не принимаются.
