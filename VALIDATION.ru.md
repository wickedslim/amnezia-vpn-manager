# Проверка установки и отката на отдельной VM

Эти действия выполняются только на одноразовой Ubuntu 24.04 VM с systemd. Рабочие VPN-серверы для проверки не используются. Для проверки Telegram берётся отдельный тестовый бот и свой ID; рабочий токен не копируется.

1. Собрать релиз: `python3 scripts/build-release.py --output /tmp/awg-release`. Проверить соседний `.zip.sha256`, распаковать ZIP в отдельную папку. Внутри выполнить `sha256sum -c SHA256SUMS`.
2. Выполнить `sudo bash install.sh --bot-only`. Проверить `systemctl is-active awg_bot`, вход владельца, отказ постороннему пользователю и `/audit`. Сохранить build ID из настроек, количество клиентов и копию базы.
3. На VM поднять отдельный тестовый AmneziaWG, подключить его, создать клиента, назначить лимит, перевыпустить конфиг. Старый конфиг должен перестать работать; адрес, накопленный трафик и месячный отчёт — сохраниться. Проверить записи журнала владельца и отдельного администратора.
4. Из второй отдельной распаковки выполнить `sudo bash update.sh`. Сравнить ID сборки, клиентов, лимиты и статистику; убедиться, что VPN-контейнер не перезапускался. Проверить отсутствие перезапусков бота в течение минуты.
5. Проверить ошибку архива: изменить файл после распаковки. `install.sh --check` должен отклонить контрольные суммы до установки. Рабочая служба и база должны остаться прежними.
6. Проверить откат при сбое установки в одноразовой VM: использовать тестовую сборку с намеренно некорректным systemd unit/точкой входа; не делать это на рабочем сервере. Сравнить восстановленные файлы, БД, предыдущую службу и возможность входа. Учесть, что `is-active` после трёх секунд не заменяет минутную проверку стабильности.
7. Отдельно включить Mini App на тестовом домене. Проверить DNS/HTTPS, истечение сессии, отказ постороннему ID, сохранение режима при обновлении и `update.sh --bot-only`. При ошибке настройки HTTPS бот может быть уже обновлён; установщик сообщает частичный успех. Проверить состояние прокси отдельно по MINIAPP.ru.md.
8. Выполнить ручное восстановление по ROLLBACK.ru.md, проверить build ID, базу и VPN. Записать результаты и путь резервной копии.

Статус: этот документ — подготовленный сценарий. Полный цикл на отдельной VM пока не выполнен; автоматические preflight-тесты установщика не являются заменой этой проверки. Контрольные суммы обнаруживают повреждение архива, но не подтверждают доверие к его издателю.
