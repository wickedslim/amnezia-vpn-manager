# AWG Docker Bot 2.0 Beta

**Бета-версия `2.0.0-beta.6`.** Переносимые установщики ещё требуют сквозной проверки на чистом VPS; начните с отдельного тестового сервера/клиента.

**Форк проекта [JB-SelfCompany/awg-docker-bot](https://github.com/JB-SelfCompany/awg-docker-bot)** с переработанным интерфейсом, надёжностью и опциональным Mini App. Исходная лицензия GPL-3.0 сохранена.

Один Telegram-бот для нескольких серверов AmneziaWG. Можно использовать **только чат-бот** или подключить **Mini App** с живыми графиками и управлением клиентами.

В настройках Mini App владелец может добавлять Telegram-администраторов по ID. Администраторы получают управление клиентами всех серверов, статистику, Speedtest и перезагрузку VPS; доступ, подключения SSH и полные бэкапы остаются у владельца. [Роли и инструкции](ADMINS.ru.md).

## Установить одной командой

Для нового бота на Ubuntu/Debian. AmneziaWG уже должен быть установлен; установщик менеджера не устанавливает сам VPN.

```bash
bash -c 'set -e; run_root() { if [ "$EUID" -eq 0 ]; then "$@"; else sudo "$@"; fi; }; command -v git >/dev/null || { run_root apt-get update; run_root apt-get install -y git ca-certificates; }; task_dir=$(mktemp -d); trap "rm -rf -- \"$task_dir\"" EXIT; GIT_TERMINAL_PROMPT=0 git clone --depth 1 https://github.com/wickedslim/amnezia-vpn-manager.git "$task_dir"; run_root bash "$task_dir/install.sh"'
```

Команда скачает публичный проект и запустит установщик. Понадобятся токен Telegram-бота и числовой Telegram ID владельца. Выберите только чат-бот, Mini App со своим доменом или бесплатный адрес DuckDNS. Не запускайте один Telegram-токен на двух серверах одновременно. [Подробная инструкция](INSTALL.ru.md).

## Обновить одной командой

Запустите в SSH-терминале VPS с установленным ботом (Ubuntu/Debian):

```bash
bash -c 'set -e; run_root() { if [ "$EUID" -eq 0 ]; then "$@"; else sudo "$@"; fi; }; command -v git >/dev/null || { run_root apt-get update; run_root apt-get install -y git ca-certificates; }; task_dir=$(mktemp -d); trap "rm -rf -- \"$task_dir\"" EXIT; GIT_TERMINAL_PROMPT=0 git clone --depth 1 https://github.com/wickedslim/amnezia-vpn-manager.git "$task_dir"; run_root bash "$task_dir/update.sh"'
```

Команда скачает актуальную ветку `main` во временную папку, создаст резервную копию и обновит бота. Сохраняются серверы, клиенты, конфиги и статистика; перезапускается только бот, VPN продолжает работать. Аккаунт и токен GitHub не нужны. Для обычного бота мастер предложит подключить Mini App через свой домен или бесплатный DuckDNS; существующая панель сохранится. Без интерактивного терминала режим сохраняется.

[Подробности обновления и отката](UPDATE.ru.md) · [Новая установка одной командой](INSTALL.ru.md)

## Удалить одной командой

Запустите в интерактивном SSH-терминале VPS, где установлен менеджер. Нужен `curl` и root либо `sudo`.

```bash
bash -c 'set -e; task_script=$(mktemp); trap "rm -f -- \"$task_script\"" EXIT; curl -fsSL https://raw.githubusercontent.com/wickedslim/amnezia-vpn-manager/main/uninstall.sh -o "$task_script"; if [ "$EUID" -eq 0 ]; then bash "$task_script"; else sudo bash "$task_script"; fi'
```

Скрипт покажет службу и каталог и попросит подтвердить удаление. Для нестандартной установки задайте `AWG_SERVICE_NAME` и `AWG_INSTALL_DIR` при ручном запуске.

[Подробности удаления и восстановления](UNINSTALL.ru.md).

## Быстрый запуск

Ubuntu 24.04 / Debian 12, systemd, Python 3.11+. VPN должен быть заранее установлен через Amnezia; установщик менеджера не устанавливает и не перезапускает VPN.

Из распакованного архива или отдельного checkout:

```bash
# Новый бот без Mini App, домена и веб-сервера
sudo bash install.sh --bot-only

# Новый бот с Mini App (свой домен и IP)
sudo bash install.sh --domain vpn.example.com --ip 203.0.113.10

# Обновить существующего бота, сохранив текущий режим
sudo bash update.sh

# Обновить и оставить только Telegram-бота
sudo bash update.sh --bot-only
```

При новой установке без флагов предлагается выбор Mini App; ответ «нет» оставляет полноценный чат-бот. Боту нужен собственный токен BotFather и Telegram ID владельца. Не используйте один токен одновременно на двух машинах.

## Возможности

- Несколько VPN-серверов по SSH в одной панели; изоляция клиентов и операций по серверу.
- Навигация в одном сообщении без постоянных закреплений; клиенты в две колонки, поиск и страницы.
- Создание, удаление, перевыпуск и повторная выдача сохранённых конфигов; сроки и лимиты трафика; резервные копии.
- Накопительный трафик и месячные отчёты по конфигам, сортировки и CSV. Удалённые конфиги остаются в отчётах.
- Mini App: темы Telegram, графики, запрос метрик каждые 5 секунд, «Скорость / Трафик», Speedtest.
- Отдельные системные счётчики всего VPS с фоновым накоплением раз в минуту.

### Как читать трафик

**VPN: ↓ на устройства, ↑ с устройств.** Это сумма по клиентам, а не сторона сервера. Например, при просмотре видео растёт «На устройства». В карточке одного клиента — «На устройство / С устройства».

**Системный VPS: «VPS получил / VPS отправил».** Здесь считаются все службы и сетевой интерфейс сервера, в том числе VPN и Speedtest. Эти суммы не обязаны совпадать с VPN-счётчиками.

Месячная статистика начинается с включения учёта. Прошлые месяцы из единственного накопительного счётчика восстановить нельзя. Полная история VPS до доступных системных счётчиков также неизвестна.

## Скачать проект

Репозиторий публичный: код и релизы доступны без приглашения, GitHub-токена и SSH-ключа. Скачайте **Code → Download ZIP** или выполните:

```bash
git clone https://github.com/wickedslim/amnezia-vpn-manager.git
cd amnezia-vpn-manager
```

Для установки/обновления одной командой используйте инструкции выше. Скрипт скачивает код в отдельную временную папку; рабочая база и настройки сохраняются при обновлении.

## Разработка и проверки

```bash
python3 -m venv .venv-dev
.venv-dev/bin/python -m pip install -r requirements.txt
TASK_PYTHON=.venv-dev/bin/python bash scripts/check.sh
.venv-dev/bin/python scripts/miniapp_preview.py
```

Демо: http://127.0.0.1:8765, только вымышленные данные во временной базе. Тесты не подключаются к рабочему VPN/Telegram; HTTP-тестам нужен локальный loopback.

Новые установщики для распространения проверены на синтаксис, аргументы и структуру. Сквозная установка на чистом VPS должна быть проверена получателем перед рабочим использованием. Миграция, UI, счётчики, SSH-транзакции и API покрыты автоматическими тестами; ручные реальные Speedtest и развёртывание предыдущего установщика проверялись отдельно.
